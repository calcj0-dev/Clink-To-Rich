# 億までチャリン 身内テストのお願い

公開前のゲームを遊んで、感想を聞かせてください。10〜20分くらいです。

## 遊ぶ場所
https://clink-to-rich.vercel.app/

スマホで開いてください（PC でも遊べます）。インストールやログインはいりません。

## 遊び方（かんたんに）
1. 画面を触って指を左右に動かし、離すとお金が落ちます
2. 同じお金がくっつくと、1つ上のお金になります（1円玉＋1円玉＝5円玉 … 1億円まで）
3. 下の「かぶ」ボタンを押すとチャートが開き、「買」でかぶ（株）を買えます。現金が減って、かぶの玉が降ってきます
4. 上の線より上にお金やかぶが残ると、貯金箱が割れて終わりです

## お願い
- **3回くらい遊んでください**
- 遊び終わったら、下の質問に答えて送ってください（箇条書きで大丈夫です）

## 質問
1. 使った端末とブラウザ（例：iPhone の Safari、Android の Chrome、X のアプリの中、PC）
2. 何回遊びましたか？ 一番よかった合計はいくら？ 称号は？
3. **かぶを買えましたか？**（買えなかった／1〜2株／3株以上）
4. **かぶを買って、得したと思いましたか？**（得した／損した／分からない）
5. 1回にかかった時間はどのくらい？（5分くらい／10分くらい／もっと長い）
6. 遊び方で分からなかったところは？
7. 動きが重い・おかしいと感じたところは？（玉がすり抜けた、落とせなかった など）
8. 音はどうでしたか？（よかった／うるさい／鳴らなかった）
9. 結果の画像を保存したり、Xでシェアしたりできましたか？
10. そのほか、気になったこと・おもしろかったこと
